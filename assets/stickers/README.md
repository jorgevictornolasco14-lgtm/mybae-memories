# Figurinhas do My Bae

Os SVGs de coração, laço, flor e estrela desta pasta são originais, criados para este projeto.

Para incluir Hello Kitty ou outros personagens, adicione somente arquivos fornecidos pelo responsável pelo site e autorizados para publicação. Nenhum asset desses personagens está incluído ou é baixado automaticamente. Registre aqui a origem e a autorização dos novos arquivos antes de publicá-los.

Use imagens decorativas com `alt=""`, `aria-hidden="true"` e a classe `sticker`; defina dimensões e mantenha-as afastadas de textos e controles. O tema usa caminhos locais desta pasta.
